# System Functions

System helpers expose runtime state, screen pointer state, nested script
execution, and debugging hooks.

## `fps()`

Returns the runtime FPS value rounded to a number. It is meaningful while the
screen runtime is drawing frames.

```piscript
println("fps " + fps(), 1, 1, COLOR_SOFT_IVORY)
draw()
```

## `error(message)`

Writes `Error: ...` to the console path and returns `nil`. In the current
implementation this is a reporting helper, not the low-level VM runtime error
raiser.

```piscript
if hp < 0
    error("hp went below zero")
```

## `zen()`

Returns the PiScript zen banner string. Print it to the screen or console if
you want to display it.

```piscript
writeln(zen())
```

## `cursor(x, y[, color])`

Moves the screen text cursor. When the optional color is provided, later screen
text calls use that text color until changed again.

```piscript
cursor(4, 4, COLOR_WARM_YELLOW)
println("score " + score)
draw()
```

## `mouse()`

Returns the current mouse coordinates as `[x, y]` in virtual-screen space.
Coordinates are clamped to `0..127`.

```piscript
let pos = mouse()
pixel(pos[0], pos[1], COLOR_SKY_BLUE)
draw()
```

## `eval(expression)`

Compiles and evaluates a PiScript expression string in a nested VM state and
returns the resulting value.

```piscript
let result = eval("6 * 7")
writeln(result)
```

## `run(path)`

Reads and executes another PiScript file. The call returns `nil` after the
nested script finishes.

```piscript
run("scripts/level.pi")
```

## `dis(code)`

Compiles a code string and writes disassembly output. It is for inspecting
compiler output while developing the language or debugging generated bytecode.

```piscript
dis("let x = 1 + 2")
```
